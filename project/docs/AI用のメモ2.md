## 切り替えによる理論上の改善余地

P4_HTを基準に、ほかの構成を採用したときの短縮時間を示します。

| v_proj    | P2   | 0.02415 ms | 1.40%短縮   |
| attention | P2   | 0.00550 ms | 0.32%短縮   |
| attn_out  | P2   | 0.00376 ms | 0.22%短縮   |

この短縮時間は固定構成の別々の実行結果を組み合わせたもので、実際の切り替えコストは含まれていません。

### 最適化方針

outputだけ切り替える方針が、現時点では最も合理的です。

- `output`：全体の46.9%を占め、P4X4への切り替えで理論上7.66%の改善余地。
- `v_proj`：2位のP4_HTより23.4%速いものの、全体への効果は最大約1.4%。
- `attention`・`attn_out`：全体への効果が小さく、切り替えコストに負ける可能性が高い。
- `ffn_*`：もともとP4_HTが最速なので変更不要。

したがって、まずは P4_HT固定経路＋outputだけP4X4に切り替える経路を低オーバーヘッドで実装するのがよいです。
