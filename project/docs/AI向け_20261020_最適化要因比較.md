## 調査の目的と現在の入口

ワーカー管理方式、行の分配、QKV融合、FFN融合を独立に変え、単独効果と相互作用を調べる。
前段の「融合pthreadは未比較」という状態から進み、今回は同じ数値カーネルで両方式を測った。
[詳細報告とデータ](../../results/factorial_20261020_164542_137621/README.md)を先に参照すること。

速度測定700回と詳細計測18回を実施。一次探索は64要因セル＋従来/切替22構成を5回ずつ。
その後、独立の上位確認、分配の通常/output分離、人数切替だけの比較も行った。
CPU、モデル、生成設定は報告書とconfig.jsonに記録。過去フェーズの絶対値を混ぜない。

## 知見

- QKV融合はOpenMP/pthreadの両方で有効。周辺平均で約0.086〜0.123ms/token短縮。
- FFN融合＋SwiGLU並列化も両方で有効。約0.036〜0.074ms/token短縮。
  この2処理の寄与はまだ独立には分離していない。
- 全行列のdynamic化はP2E8の10人構成で約0.093〜0.130ms短縮。
  8人では周辺平均の効果は小さい/不確か。Attentionの分配は静的なまま。
- 4行同時計算は方式・粒度・CPU依存。pthread10では平均で有効だが一律に有効ではない。
- QKV×FFNの強い相乗効果は全条件で一貫していない。
  静的pthread10・1行では効果が重なる兆候。dynamicや4行の条件にも一般化しない。
- 通常部分とoutputを両方dynamicにしても短縮が単純な足し算にはならない。
  P2E8 OpenMPではoutput側の寄与が大きく、両方併用時は単独短縮の合計より小さかった。
- 重み2は今回の静的4→8切替で有利でなかった。適切な重み付け一般の否定ではない。

同じ融合・dynamic・output1行を揃えた10回比較（tokens/s）:

| 通常→output | OpenMP | pthread常駐 |
|---|---:|---:|
| 8→8 | 763.88 | 745.35 |
| 8→14 | 700.55 | 761.19 |
| 14→14 | 613.06 | 611.05 |

今回の切替効果は方式によって異なった。OpenMPは8固定から0.118ms悪化。
pthreadは0.028ms改善傾向だが95%探索区間がゼロ付近まで含み、小差の確証は弱い。
「両方式の切替効果の差」は約0.146msで区間[0.117,0.171]。
全14固定が不利でも、outputだけ14人を使うことまで否定しない。
OpenMPもワーカーを再利用し得る。測定差をOSスレッドの生成終了だけに帰属させない。

追加確認の固定10人・融合＋dynamic・4行32物理行ではOpenMP774.55、pthread746.15 tok/s。
方式差は最適化や人数切替の条件に依存する。pthread常駐一般が悪い、OpenMP一般が優れると解釈しない。

## 実装・再測定

- `src/parallel.h`: OpenMPと実験pthreadで共通の数値カーネル。
- `src/stay.h`: 従来の常駐プールを維持し、実験時のみatomic行キューを追加。
- `backend="openmp" / "pthread"`: LLAMA_EXPERIMENT付きの条件を揃えた比較経路。
- `backend="upstream" / "stay" / "parallel"`: 比較用の従来経路を残す。
- `fuse_qkv`と`fuse_ffn`を独立指定。Noneなら従来の`fuse`設定を継承する。
- `omp_schedule`: 両実験方式の通常行列の設定。static / dynamic,16を比較。
- `output_dynamic`: outputだけ独立指定できる。実験経路でNoneなら通常側を継承。
- 実験経路の`output_chunk`は物理行数。4行化時も粒度を揃える。
  従来parallelはブロック数だったので、比較時に単位を混同しない。
- pthreadはcpus全体を常駐させ、threads人が層に参加し、outputにはcpus全員が参加する。
- `benchmark_factorial.py`をPython/IDEから実行すると430回の要因比較と集計を行う。
  設定、環境変数、ビルドはPythonで管理し、shellの操作を要求しない。
- `analyze_factorial.py`: ブロック内の対比較で効果と相互作用を求める。
  正の値が短縮。相乗短縮は T(Aのみ)+T(Bのみ)-T(両方)-T(なし)。
