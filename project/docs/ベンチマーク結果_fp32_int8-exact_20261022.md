# ベンチマーク結果: 出力層 fp32 と int8-exact（2026-10-22）

ブランチ `feature/cpu-profiler-split-beam`（da5461e5 = `bench/cpu-profiler-int8-exact-split-beam`）の cpuprofiler で、出力層の計算方法（`-q`）を変えて計測した。

## 条件

- CPU: Intel Core Ultra 5 225U（14 論理 CPU）
  - CPU 0–3: P コア（2 コア × HT、最大 4.8 GHz）
  - CPU 4–11: E コア（8 コア、最大 3.8 GHz）
  - CPU 12–13: LP E コア（2 コア、最大 2.4 GHz）
- モデル: stories15M.bin
- `steps=256, temperature=0.0, seed=42, prompt="Once upon a time"`
- `OMP_PROC_BIND=TRUE, OMP_PLACES=threads, OMP_DYNAMIC=false, OMP_SCHEDULE=dynamic,128`
- 探索
  - beam: 全体を同じ CPU 集合で動かし、CPU 集合を beam search（1〜8 スレッド、209 構成）
  - split: 出力層以外（body）と出力層（cls）の CPU を別々に beam search（`-B` / `-C`）。body を探してから、その body に固定して cls を探す（1 周）

## まとめ

| 探索 | 出力層 | 最速の CPU | tok/s | fp32 との比較 |
|---|---|---|---:|---:|
| beam | fp32 | (0, 1, 3, 5, 6, 7, 9, 10) | 633.2 | — |
| beam | int8-exact | (0, 1, 3) | 840.3 | +32.7% |
| split | fp32 | body (1, 3) / cls (1, 2, 4, 6, 7, 8, 9, 11) | 646.2 | — |
| split | int8-exact | body (0, 2) / cls (0, 1, 2, 3, 7, 9) | 850.0 | +31.5% |

- int8-exact にすると、beam・split ともに約 32% 速くなる。
- split は beam より fp32 で +2.0%、int8-exact で +1.2% 速い。差は小さい。

## split の区間ごとの時間

| 出力層 | body ms/tok | cls ms/tok | 合計 ms/tok | body の割合 |
|---|---:|---:|---:|---:|
| fp32 | 0.890 | 0.629 | 1.519 | 59% |
| int8-exact | 0.909 | 0.240 | 1.149 | 79% |

- 出力層は 0.629 → 0.240 ms/tok（2.6 倍速）。
- body はどちらも約 0.9 ms/tok で、P コア 2 つ（HT の別コア同士）が最速。
- int8-exact では、時間の約 8 割が body になる。これ以上速くするには、body（層の計算）を速くする必要がある。

## beam のスレッド数ごとの最速

| スレッド数 | fp32 の CPU | fp32 tok/s | int8-exact の CPU | int8-exact tok/s |
|---:|---|---:|---|---:|
| 1 | (3) | 443.8 | (1) | 646.2 |
| 2 | (1, 2) | 549.8 | (1, 3) | 795.0 |
| 3 | (0, 1, 2) | 571.1 | **(0, 1, 3)** | **840.3** |
| 4 | (0, 1, 3, 5) | 581.6 | (0, 1, 2, 3) | 830.8 |
| 5 | (0, 1, 3, 4, 5) | 600.5 | (0, 1, 2, 4, 10) | 821.6 |
| 6 | (0, 1, 3, 5, 10, 11) | 622.5 | (0, 1, 2, 5, 8, 9) | 827.7 |
| 7 | (0, 1, 3, 5, 6, 9, 10) | 627.8 | (0, 1, 2, 4, 6, 7, 8) | 827.7 |
| 8 | **(0, 1, 3, 5, 6, 7, 9, 10)** | **633.2** | (0, 1, 2, 4, 6, 7, 8, 11) | 818.5 |

- fp32 は、E コアを足すほど少しずつ速くなる（出力層の fp32 の行列計算が重いため）。
- int8-exact は P コア 3 スレッドが最速で、E コアを足しても速くならない（少し遅くなる）。
- どちらも LP E コア（12, 13）が入ると大きく遅くなる。

## 注意

- 各構成は 1 回しか測っていない。tok/s の刻みが粗く、上位はほぼ同じ値に並ぶ（例: fp32 の 8 スレッド上位 5 つは 631.4〜633.2）。数 % 以内の差は誤差と考える。
- 生成されたテキストは fp32 と int8-exact で同じ（`-t 0 -s 42`、64 トークンで確認）。
